# Icons

Eight 16×16 pixel icons drawn for Nell, single-ink **`cream`** (`#f5d4c9`) with crisp edges. Show them at 16px or 32px only. On `leaf` (Allow) buttons, darken them to `outline` with `filter: brightness(0)`.

| File | Used for |
|---|---|
| nell-chat.svg | The 💬 Chat mode chip and badge |
| nell-code.svg | The ⌘ Code mode chip and badge |
| nell-allow.svg | The Allow button |
| nell-deny.svg | The Deny button and the error header |
| nell-terminal.svg | Open terminal / Answer in terminal |
| nell-alert.svg | NEEDS YOU and HEADS UP headers |
| nell-more.svg | The QUESTION header, and truncation |
| nell-sleepy.svg | The sleepy state hint |
