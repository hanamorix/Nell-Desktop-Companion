# Character

- **nell-pixel-reference.png**: the user's 150×150 pixel-art Nell. It is the art direction for every sprite strip, and the source of this system's palette (hoodie plums, hair browns, skin creams, eye pinks, and the `outline`).
- **nell-typing-concept.png**: the original smooth 4-frame typing concept from the repo (`art/concept/`). It is not pixel art; the app uses it only as a placeholder until the sprite sheets exist.

Sprites are exported from Aseprite as sheets with JSON frame data, and drawn with nearest-neighbour scaling at a whole-number zoom.
