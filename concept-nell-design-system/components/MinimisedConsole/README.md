# MinimisedConsole

The console, put away: a quiet one-line strip next to Nell that says what Claude Code is doing. Clicking it opens the console again.

## Rules
- It shows only while the console is minimised. Code's status lives here then, instead of in a status bubble.
- With nothing running it reads "Claude Code is idle".

## Look
A `plum-800` strip with a `plum-600` top edge, a `plum-900` bottom bevel and the usual `drop`. The code icon and the status line in `text-muted`, and a `pink-400` OPEN label on the right. No tail: like a status bubble, it is muttering, not speaking.

## What the consumer provides
The status text and the open action.
